# Donde Te Llevo - Landing Page
Bienvenido al repositorio del sitio web público de Donde Te Llevo. Este proyecto es la cara visible de la empresa, diseñada para atraer tanto a clientes corporativos (transporte de personal) como particulares (eventos especiales).

🚀 Tecnologías
Framework: React 18 + Vite (TypeScript)

Estilos: Tailwind CSS

Despliegue: Vercel

Formularios: Integración vía API REST con D_T_LL Backend.

📂 Estructura del Proyectotext
/src /assets # Imágenes, logos y fuentes /components # Botones, Headers, Footers reutilizables /pages # Secciones (Inicio, Servicios, Contacto) /services # Conexión con el Backend (envío de leads)

## 🛠️ Instalación y Desarrollo

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/TU_USUARIO/D_T_LL-Landing-Page.git](https://github.com/TU_USUARIO/D_T_LL-Landing-Page.git)
    cd D_T_LL-Landing-Page
    ```

2.  **Instalar dependencias:**
    ```bash
    npm install
    ```

3.  **Correr servidor de desarrollo:**
    ```bash
    npm run dev
    ```
    Visita `http://localhost:5173` para ver la aplicación.

## 📦 Despliegue

Este proyecto está configurado para desplegarse automáticamente en **Vercel** al hacer push a la rama `main`.
